# 球拍圖片（照系列，一系列一張）

程式照**系列**抓圖，不用每支拍一張。放這裡：

```
public/racquets/speed.png
public/racquets/radical.png
public/racquets/gravity.png
public/racquets/extreme.png
public/racquets/boom.png
public/racquets/prestige.png
public/racquets/squared.png
public/racquets/_cover.png   ← 開場封面主視覺
```

- 支援副檔名：`.webp` / `.png` / `.jpg`（程式依序試，找不到就用線框 fallback）。
- **強烈建議去背 PNG（透明底、只有球拍、無文字/logo）** —— 深黑 UI 上才好看。
  白底 + 印死行銷字的商品圖會變成一塊白方塊，很突兀。
- 直式構圖最佳（球拍立著），比例約 1 : 1.6。

檔名用系列小寫：speed / radical / gravity / extreme / boom / prestige / squared。
